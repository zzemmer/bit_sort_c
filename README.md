# Сортировка бинарных файлов с записями фиксированной длины

Консольная утилита на языке C для сортировки бинарных файлов. Разработана в рамках курсовой работы по дисциплине "Основы программирования систем управления" (РТУ МИРЭА).

## Стек
* Язык: **C (C99)**
* Компилятор: GCC

## Ключевые особенности реализации
* **Работа с памятью:** Все данные загружаются в ОЗУ, сортируются и записываются за одну операцию (минимизация дисковых I/O).
* **Low-level parsing:** Извлечение ключа из массива байтов с учетом порядка **little-endian** (через побитовые сдвиги).
* **Безопасность:** Полный контроль ошибок при работе с файловой системой (`fopen`, `fread`, `fwrite`) и динамической памятью (`malloc`, `free`).
* **Алгоритм:** Самостоятельная реализация устойчивой пузырьковой сортировки с побайтовым обменом элементов.

## Файлы
* `main.c` — исходный код программы.
* `Coursework_Report.pdf` — полный отчет по курсовой работе (включая блок-схемы и тестирование).
